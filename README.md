# Volatility 3 DFIR Web Application

تطبيق ويب جنائي متكامل ومستقل مبني بلغة بايثون بنسبة 100% لفحص وتحليل الذاكرة العشوائية (Memory Forensics) بالاعتماد على إطار العمل الجنائي **Volatility 3 Framework**.

---

## المميزات الرئيسية (Core Features)

1. **بنية مستقلة بالكامل (Pure-Python Standalone Backend):**
   - تحرر تام من مكتبات واجهات سطح المكتب (`PySide6` / `Qt`)؛ التطبيق يعمل كخادم ويب خالص باستخدام `Flask` و `Threading`.
   - خفيف وسريع ويدعم العمل محلياً وعبر الشبكة عبر متصفحات الإنترنت (Chrome, Edge, Firefox).

2. **حل مشكلة الرسم البياني الجنائي (Fixed Forensic Interactive Graph):**
   - تم حل المشكلة السابقة التي كانت تمنع ظهور الروابط بين العمليات؛ حيث يولد محرك `core/graph_builder.py` الآن شجرة العمليات الكاملة بروابط الأبوة والتفريخ (`PPID -> PID` `spawns`) إضافة إلى اتصالات الشبكة وحقن الذاكرة ومطابقات YARA.
   - محاكاة فيزيائية حية بالقوى (Force-Directed Graph Simulation) مع تحريك العقد، الفلترة حسب النوع، والبحث اللحظي، والضغط المزدوج لفتح تفاصيل العملية.

3. **توافقية كاملة مع الواجهة (Dual-API Architecture):**
   - **Bridge Compatibility Layer (`/api/bridge/<slot>`)**: تدعم واجهة العميل السابقة بسلاسة مع دعم Server-Sent Events (SSE) للبث المباشر لسجلات ومخرجات الفحص في الطرفية التفاعلية.
   - **RESTful Endpoints (`/api/*`)**: وصول مباشر للقضايا، الأدلة، العمليات، الشبكة، الفحوصات، ومخطط العلاقات بصيغة JSON.

4. **محركات التحقيق الجنائي المتطورة:**
   - **Cross-Plugin Correlation Engine**: ربط نتائج العمليات (`pslist`, `psscan`, `pstree`) مع الشبكة والذاكرة وحقن الأكواد لاكتشاف تقنيات التخفي و DKOM.
   - **Risk Scoring & Heuristic Engine (0-100)**: تقييم العمليات المشبوهة وقواعد الكشف المخصصة.
   - **Threat Hunter & IOC Extractor**: استخراج مؤشرات الاختراق من اتصالات الشبكة، حماية من هجمات ReDoS، وتصدير STIX 2.1.
   - **Forensic Timeline**: تسلسل زمني دقيق لإنشاء العمليات وإنهائها والاتصالات الخارجية.
   - **Multi-Step Playbook Automation**: أتمتة الفحص الشامل عبر سيناريوهات محددة مسبقاً مع تحديث لحظي للتقدم.
   - **Snapshot Diffing**: مقارنة ذاكرتين عشوائيتين لإظهار العمليات الجديدة أو المحذوفة ومسارات التسلل.
   - **Court-Admissible Arabic RTL Reports**: توليد تقارير جنائية محترفة باللغة العربية مطابقة لمعايير ISO/IEC 27037 جاهزة للطباعة والتصدير.

## متطلبات التشغيل (Requirements)

- **Python 3.10+** (مُثبت ومُهيأ في النظام)
- الحزم البرمجية:
  ```bash
  pip install -r requirements.txt
  ```
  *(تشمل `flask`, `volatility3`, `pyyaml`, `yara-python`)*

---

## طريقة التشغيل (How to Run)

### الطريقة الأولى: بنقرة زر واحدة
اضغط مرتين على الملف:
```cmd
run.bat
```
سيقوم ببدء الخادم وفتح المتصفح تلقائياً على العنوان: `http://127.0.0.1:8000`.

### الطريقة الثانية: من موجه الأوامر (Terminal)
```bash
python app.py
```
ثم افتح متصفحك على: `http://127.0.0.1:8000`.
